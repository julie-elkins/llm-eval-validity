## Full-manuscript gate

The full manuscript should be submitted only if the editors invite it. Before
that submission:

- [ ] Obtain at least two research-method reviews.
- [ ] Recheck all aggregate counts against the frozen fixture.
- [ ] Keep the synthetic reference disposition private.
- [ ] Add any required journal formatting and reference style.
- [ ] Preserve the no-participant and no-learning-outcome limitation.
- [ ] Complete the journal's ethics, data-availability, and AI-use statements.
- [ ] Decide whether a human-validation phase has an approved ethics route.
- [ ] Do not add human results after seeing the synthetic result unless the
  protocol and analysis plan are formally revised.

## Release boundary

The public repository may contain the protocol, metadata-only cases, analysis
code, tests, aggregate results, and claim limitations. It must not contain
participant answers, private certification material, answer keys, reviewer
identities, raw provider traces, credentials, or private reference
dispositions.
